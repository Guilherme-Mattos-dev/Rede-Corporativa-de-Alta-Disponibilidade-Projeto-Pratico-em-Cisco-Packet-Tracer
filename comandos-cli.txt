Comandos CLI — Rede Corporativa

VLANs

vlan 10
 name Gerencia
exit

vlan 20
 name Desenvolvimento
exit

vlan 30
 name Comercial
exit

vlan 40
 name Servidores
exit


Portas de acesso

interface range fastEthernet 0/1-8
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 spanning-tree bpduguard enable
exit

Nas demais portas de acesso, o número da VLAN deve ser alterado de acordo com o setor.


EtherChannel / LACP — Grupo 1

No SW-ACESSO-1:

interface range fastEthernet 0/23-24
 channel-group 1 mode active
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40
exit

No CORE-1:

interface range fastEthernet 0/1-2
 channel-group 1 mode active
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40
exit

Os grupos 2, 3 e 4 seguem a mesma lógica, utilizando as portas definidas para cada switch.


Roteamento Inter-VLAN — CORE-1

ip routing

interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
exit

interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown
exit

interface vlan 30
 ip address 192.168.30.1 255.255.255.0
 no shutdown
exit

interface vlan 40
 ip address 192.168.40.1 255.255.255.0
 no shutdown
exit


DHCP Relay — CORE-1

interface vlan 10
 ip helper-address 192.168.40.10
exit

interface vlan 20
 ip helper-address 192.168.40.10
exit

interface vlan 30
 ip helper-address 192.168.40.10
exit

Teste de conectividade

Também pode ser utilizado ping entre PCs de switches de acesso diferentes, desde que estejam na mesma VLAN.
